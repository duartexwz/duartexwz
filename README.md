### 🚀 Projetos em Destaque

#### 💅 [Ana Clara Nails — Sistema de Agendamento Online](https://github.com/duartexwz/anaclara-nails)
Sistema completo de agendamento para nail designer: catálogo de modelos, reserva de horário com pagamento do **sinal (50%) via Mercado Pago**, painel administrativo (agenda, clientes, mensagens, equipe) e notificações (Web Push + e-mail).

- **Stack:** React 19 + TanStack Start/Router · FastAPI + PostgreSQL (asyncpg) · Docker/Nginx · Vercel
- **Destaques:** Checkout Bricks (Pix/cartão), webhook com validação HMAC-SHA256, upload de fotos no Cloudflare R2, 243 testes pytest (sem banco)
- **Rotas:** cliente (`/catalogo`, `/agendamento`, `/meus-agendamentos`) e admin (`/admin/*`)

#### 📅 [Sistema de Reservas Institucionais — COFFITO](https://github.com/CoffitoProjects/agendamento-coffito)
Aplicação para solicitação, análise e acompanhamento de reservas de espaços institucionais do COFFITO, com fluxo público (sem login) e fluxo interno (painel, agenda, administração).

- **Stack:** FastAPI + PostgreSQL · React (Vite, JS) + Bootstrap 5 + FullCalendar · Docker
- **Destaques:** autenticação por cookie `HttpOnly` + CSRF, agenda pública para monitores, Mailpit para testes de e-mail, sidebar recolhível no padrão GPLI

#### 🩺 [Agendamento Saúde Ocupacional (Fisioterapia/TO)](https://github.com/duartexwz/agendamento-fisioterapia-coffito)
Sistema de agendamento de sessões de fisioterapia/terapia ocupacional com painel administrativo e página pública.

- **Stack:** Node.js + Express · Frontend em HTML/CSS/JS puro (sem build) · Persistência em JSON · Docker
- **Destaques:** regras de vagas/lotado, testes automatizados com Jest + Supertest, volume nomeado para persistência no Docker

#### 🛒 [JP Croco — Loja Online (E-commerce)](https://github.com/duartexwz/loja-online)
Plataforma de e-commerce completa com catálogo, carrinho, pedidos, pagamento via Mercado Pago, cálculo de frete (Correios), rastreio e painel administrativo.

- **Stack:** FastAPI + PostgreSQL · Frontend HTML/CSS/JS · Docker + Nginx
- **Destaques:** push notifications (VAPID), upload de imagens, recuperação de senha por e-mail, frete e rastreio integrados

#### 🌐 [Landing Page + Painel Admin — mayckon.dev](https://github.com/duartexwz/landingpage)
Landing page dark de alta conversão para serviços (APIs, Landing Pages, Web Apps e Automações), com formulário de orçamento e painel administrativo para edição de conteúdo.

- **Stack:** React 18 + Vite · FastAPI + PostgreSQL · Vercel (front estático + função Python)
- **Destaques:** uploads no Cloudflare R2/Vercel Blob, cache de borda, 7 tabelas com migrations idempotentes, testes pytest

#### 👨‍💻 [Portfólio Pessoal 2.0](https://github.com/duartexwz/portifolio-2.0)
Portfólio pessoal com animações (GSAP + ScrollTrigger, particles.js), carrossel de projetos com detalhes expansíveis e formulário de orçamento via WhatsApp.

- **Stack:** HTML5/CSS3/JS (ES Modules) · Nginx (Alpine) · Docker
- **Destaques:** tema escuro, layout responsivo, otimizado para deploy em container

#### 📚 [Curso Dev Web (estudos)](https://github.com/duartexwz/curso-dev-web)
Repositório de estudos e exercícios de desenvolvimento web (JavaScript, DOM, eventos, POO, arrays) e pequenos projetos práticos (ex.: página estilo Instagram).

- **Stack:** HTML/CSS/JavaScript
